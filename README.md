# Mangayomi 미디어 확장

Mangayomi에서 애니메이션과 영화·드라마의 작품 목록, 검색 결과, 상세 정보, 회차 및 재생 주소를 가져오는 JavaScript 확장 모음입니다. 각 확장은 사이트별 API 또는 HTML을 읽어 앱의 공통 데이터 형식으로 변환합니다.

이 폴더에는 확장 JavaScript 5개와 배포용 JSON 목록이 있습니다. 확장은 Mangayomi의 JavaScript 실행 환경에서 동작하며, 별도의 패키지 설치나 빌드 과정은 없습니다.

## 확장 목록

버전과 기본 주소는 현재 파일에 선언된 값입니다. 사이트의 현재 접속 가능 여부를 나타내지는 않습니다.

| 확장 | 소스 | 버전 | 기본 주소 | 주요 기능 |
| --- | --- | --- | --- | --- |
| 링크애니 | [linkani.js](linkani.js) | 0.2.0 | `https://linkani.tv` | 인기·최신·검색, 분류·요일·형식·연도 필터, 회차별 서버, HLS/MP4·자막 |
| 애니24 | [ani24.js](ani24.js) | 0.1.19 | `https://ani.ohli24.com` | 방영중·완결·극장판·연도별·TOP5 목록, 검색, 탭 규칙 저장, 제목 언어·목록 카드 |
| 애니라이프 | [anilife.js](anilife.js) | 0.2.1 | `https://anilife01.tv` | 작품·재생 API, 정렬·형식·상태·요일·연도 필터, 한국어·일본어 제목, 자막 |
| ReAnime | [reanime.js](reanime.js) | 0.1.6 | JS: `https://reanime.cz` / JSON: `https://reanime.to/` | 한국어 검색어 변환, 장르·형식·상태·계절·연도 필터, HD-1/HD-2, 오디오·자막 |
| 코티비씨 | [kotbc.js](kotbc.js) | 0.1.1 | `https://k03.kotbc2.com` | 영화·드라마·예능시사·해외드라마, 평점순·최신순, 검색·필터, 회차 페이지 수집, HLS/MP4 |

**애니라이프는 등록 JSON의 `notes`에 `현재 고장남`으로 표시되어 있습니다.** 위 기능은 코드에 구현된 범위이며, 정상 동작을 보장하는 표기는 아닙니다. ReAnime의 등록 정보 불일치는 아래의 알려진 문제를 참고하세요.

## 설치 및 업데이트

1. Mangayomi의 확장 저장소 설정에 다음 확장 목록 URL을 등록합니다.
2. 저장소 목록을 새로고침하고 사용할 확장을 설치하거나 업데이트합니다.
3. 확장 설정에서 사이트 주소, 제목 언어, 자막 등의 옵션을 확인합니다.
4. 작품 목록에서 상세와 회차를 열어 재생을 확인합니다.

```text
https://raw.githubusercontent.com/wsun1023/mangayomi/main/mangayomi-extensions-updated.json
```

현재 [등록 목록](mangayomi-extensions-updated.json)의 최소 Mangayomi 버전(`appMinVerReq`)은 5개 모두 `0.9.2`입니다. ReAnime의 JS 내부에는 `0.5.0`이 선언되어 있어 배포 정보와 차이가 있습니다.

이 URL은 파일에 기록된 배포 경로입니다. 다른 GitHub 저장소나 브랜치에서 배포할 때는 등록 URL과 각 항목의 `sourceCodeUrl`을 해당 경로로 변경해야 합니다.

## 파일 구성

```text
.
├── README.md                         # 사용·개발 안내
├── mangayomi-extensions-updated.json  # 확장 5개의 설치·업데이트 메타데이터
├── ani24.js                          # 애니24 HTML 파싱 및 영상 서버 해석
├── anilife.js                        # 애니라이프 API 및 쿠키 세션 처리
├── kotbc.js                          # 코티비씨 페이지 JSON 및 재생 주소 발급
├── linkani.js                        # 링크애니 HTML 및 플레이어 데이터 파싱
└── reanime.js                        # ReAnime API, 스트림 복호화 및 mpv EDL 구성
```

현재 파일 구성에는 `package.json`, 자동 테스트 파일, CI 설정이 포함되어 있지 않습니다. JSON의 `pkgPath` 값은 확장 메타데이터이며 이 폴더의 실제 디렉터리 경로와는 다릅니다.

## 코드 구조와 동작

각 JS 파일은 `mangayomiSources`에 확장 정보를 선언하고 `DefaultExtension extends MProvider`로 동작을 구현합니다. 파일마다 같은 클래스 이름을 사용하므로 개별 확장으로 로드해야 합니다.

Mangayomi가 제공하는 주요 객체는 다음과 같습니다.

| 객체 | 역할 |
| --- | --- |
| `MProvider` | 확장 제공자 기본 클래스와 앱 연동 |
| `Client` | HTTP GET/POST 요청 |
| `SharedPreferences` | 사용자 설정과 캐시 저장 |
| `Document` | 애니24에서 사용하는 HTML 파싱·CSS 선택자 조회 |

주요 진입점은 모든 확장에 공통으로 구현되어 있습니다.

| 메서드 | 역할 |
| --- | --- |
| `getPopular(page)` | 인기 탭 목록 조회 |
| `getLatestUpdates(page)` | 최신 탭 목록 조회 |
| `search(query, page, filters)` | 검색 또는 필터 목록 조회 |
| `getDetail(url)` | 작품 정보와 회차 목록 조회 |
| `getVideoList(url)` | 영상 주소, 요청 헤더, 자막·오디오 정보 반환 |
| `getFilterList()` | 검색 화면 필터 정의 |
| `getSourcePreferences()` | 확장 설정 정의 |

목록은 `{ list, hasNextPage }` 형식이며 각 작품에는 `name`, `link`, `imageUrl`이 들어갑니다. 상세의 회차는 `chapters`로 전달하고, 애니24·애니라이프·링크애니·코티비씨는 같은 목록을 `episodes`에도 제공합니다. 재생 항목에는 `url`, `originalUrl`, `quality`, `headers`, `subtitles` 등이 포함됩니다.

`link`와 회차의 `url`은 확장별 식별 형식이 다릅니다. 예를 들어 애니24는 상대 경로를, ReAnime는 작품 ID와 `AniList ID|회차 번호`를 사용합니다. 호출자는 이 값을 임의로 바꾸지 않고 다음 진입점으로 전달해야 합니다.

### 링크애니

- 인기 목록은 `/label/topday/`, 최신 목록은 `/list/2/`에서 가져옵니다.
- 작품 카드와 페이지 이동 링크를 HTML에서 추출합니다. 검색어가 있으면 `/view/?wd=...`를 사용하고, 검색어가 없으면 선택한 분류·요일·형식·연도 조건을 목록 경로에 반영합니다.
- 상세에서 작품 정보와 `/watch/{작품 ID}/a{서버}/k{회차}/` 링크를 읽습니다. 같은 회차에 여러 서버가 있으면 이름으로 구분합니다.
- 재생 페이지의 플레이어 JSON, 서버 전환 링크, `video`·`source` 태그에서 HLS/MP4 주소를 찾습니다. 인코딩된 주소를 해석하고 HLS 화질 목록과 사이트 자막을 반환합니다.
- 원제 설정은 상세 제목에 적용되며, 목록 제목은 사이트 표기를 유지합니다.

### 애니24

- 사이트 HTML과 페이지에 포함된 데이터를 파싱해 목록·상세·회차를 구성합니다. 회차 목록에 다음 페이지가 있으면 추가로 수집합니다.
- 기본 인기 탭은 **방영중 + 한국 시간의 오늘 요일 + 업데이트순**, 최신 탭은 **방영중 + 전체 요일 + 업데이트순**입니다.
- 필터에서는 방영중·완결·극장판·연도별·TOP5 중 한 구역을 선택합니다. 선택한 조건을 인기·최신 탭의 규칙으로 저장하거나 기본값으로 복원할 수 있습니다.
- 검색은 `/bbs/search.php?stx=...`를 우선 사용하며, 결과가 없으면 검색어 변형과 카탈로그 검색을 시도합니다.
- 일본어 제목은 상세의 원제를 우선 사용하고, Anissia·애니라이프·AniList 등의 메타데이터로 보완합니다. 목록에서는 앞쪽 최대 8개 항목에 제목 변환을 시도합니다.
- 인기·최신 첫 페이지에는 안내 카드가 추가됩니다. 사용자 카드, 공용 이벤트 카드, 공용 목록 카드 순서로 선택하며, 사용자 카드 주소를 설정하면 이벤트 카드는 생략합니다.
- 회차의 직접 영상 주소와 외부 iframe 서버를 병렬로 확인합니다. FirePlayer 계열 영상 API와 HLS 화질 목록을 처리합니다.

### 애니라이프

- `/api/anime`에서 목록·검색 결과를, `/api/anime/{ID}`에서 상세 정보를 읽습니다.
- 회차 배열이 없으면 API가 제공한 회차 수로 목록을 구성하며, 이때 최대 2,000개까지 생성합니다.
- `/api/playback/{ID}/{회차}`에서 영상·백업 영상·자막 주소를 가져옵니다. 401·403 등 권한 오류가 발생하면 작품 페이지와 세션 API를 통해 쿠키 갱신 후 재시도합니다.
- 익명 쿠키는 제공자 인스턴스의 메모리에 보관합니다. 같은 사이트의 표지 이미지는 `wsrv.nl` 이미지 중계를 사용합니다.
- HLS 마스터 목록에서 화질별 주소를 추출합니다. 실제 세션 수락 여부와 재생은 별도 사이트 검증이 필요합니다.

### ReAnime

- `/api/v1/search`, `/api/v1/home/latest-aired`, `/api/v1/anime/{ID}` 계열 API를 사용합니다. 최신 목록의 커서 기반 페이지 이동을 앱의 페이지 번호에 맞게 캐시합니다.
- 한국어 검색어가 있으면 Anissia와 AniList에서 원제 후보를 구합니다. 선택적으로 TMDB를 함께 사용하며, 후보 검색 결과를 작품 ID로 중복 제거합니다.
- `/api/flix/{AniList ID}/{회차}`에서 서버를 찾고 Flixcloud 플레이어 데이터를 해석합니다.
- SHA-256, HMAC, PBKDF2, AES-CBC와 제한된 WASM 명령 해석기를 JavaScript로 구현해 암호화된 재생 데이터를 처리합니다.
- HLS 세그먼트를 mpv용 `edl://` 주소로 구성하고 외부 오디오·자막 트랙을 전달합니다. 일반 HTTP 영상 주소와 다른 형식이므로 플레이어 호환성을 확인해야 합니다. `EXT-X-MAP`을 사용하는 fMP4 목록은 현재 처리하지 않습니다.
- 서버 선택은 기본 HD-1이며 HD-2를 추가할 수 있습니다. 재생 결과는 회차·오디오·서버 설정을 기준으로 5분간 캐시합니다.

### 코티비씨

- HTML의 `data-page` 또는 페이지 JSON에서 `props`를 읽어 목록·상세·회차를 구성합니다.
- 인기 탭은 **평점 높은순**, 최신 탭은 **업데이트 최신순**입니다. 검색에서는 종류·정렬·장르·연도 조건을 사용할 수 있습니다.
- 상세에서 회차 페이지를 순회하고 중복을 제거한 뒤 회차 순서의 내림차순으로 정렬합니다. 100페이지를 초과하면 오류를 반환합니다.
- 일부 영상 서버는 익명 세션의 `XSRF-TOKEN`으로 `/glamov-token/{contentId}`에 재생 주소를 요청합니다. 발급된 플레이어 주소를 Referer로 사용해 FirePlayer 영상 API를 호출합니다.
- 직접 HLS/MP4, 플레이어 스크립트의 영상 주소, 중첩 iframe을 처리하고 재생 헤더와 사이트 자막을 함께 반환합니다.

## 확장 설정

| 확장 | 주요 설정과 기본 동작 |
| --- | --- |
| 링크애니 | 사이트 주소, 상세 제목 언어(기본 한국어), 사이트 자막 끄기(기본 꺼짐) |
| 애니24 | 작품 제목 언어(기본 한국어), 사이트 주소 직접 지정, 커스텀 목록 카드 JSON 주소 |
| 애니라이프 | 사이트 주소, 작품 제목 언어(기본 한국어), 사이트 자막 끄기(기본 꺼짐) |
| ReAnime | 사이트 주소, 제목 언어(기본 English), 서버(기본 HD-1), 오디오 순서(기본 Sub → Dub), TMDB 키·토큰(선택) |
| 코티비씨 | 사이트 주소, 인기·최신 종류(기본 전체), 사이트 자막 끄기(기본 꺼짐) |

`사이트 자막 끄기`를 켜면 외부 자막을 플레이어에 전달하지 않습니다. 영상에 포함된 자막에는 영향을 주지 않습니다. ReAnime의 Sub/Dub는 원어·더빙 오디오 선택이며, 한국어 검색 지원이 한국어 자막 제공을 의미하지는 않습니다.

애니24의 사이트 주소 설정은 코드에서 허용한 `ani.ohli24.com`과 기존 `ohli24.net` 계열로 제한됩니다. 기존 주소는 `ani.ohli24.com`으로 변환되므로, 다른 도메인으로 이전하면 코드의 허용 규칙도 수정해야 합니다.

## 외부 서비스 의존성

각 콘텐츠 사이트와 해당 영상 서버 외에도 다음 연결을 사용합니다. 별도 로컬 서버는 필요하지 않습니다.

| 대상 | 용도 |
| --- | --- |
| Anissia·AniList | 애니24 제목 메타데이터 보완, ReAnime 한국어 검색어 변환 |
| 애니라이프·링크 계열 사이트, `wankyo83.github.io`의 도메인 JSON | 애니24 제목 보완 및 보완용 애니라이프 주소 조회 |
| `dc-toki-mangayomi-novel.pages.dev`·`dc-toki-mangayomi-media.pages.dev` | 애니24 공용 목록·이벤트 카드 |
| `wsrv.nl` | 애니라이프 표지 이미지 중계 |
| TMDB | 키 또는 Read Access Token을 설정한 경우 ReAnime 검색 보완 |
| Flixcloud·영상 CDN | ReAnime 재생 데이터·영상 세그먼트 조회 |

애니라이프·링크애니·코티비씨의 목록·재생 처리는 각 사이트에 직접 연결합니다. 애니24에는 카드와 제목 보완을 위한 외부 의존성이 남아 있습니다.

## 개발 및 확인 방법

Node.js를 설치한 환경에서 프로젝트 폴더를 열고 JavaScript 문법을 확인할 수 있습니다. 추가 npm 패키지는 필요하지 않습니다.

```sh
node --check ani24.js
node --check anilife.js
node --check kotbc.js
node --check linkani.js
node --check reanime.js
```

등록 JSON의 구문은 다음 명령으로 확인합니다.

```sh
node -e 'JSON.parse(require("node:fs").readFileSync("mangayomi-extensions-updated.json", "utf8")); console.log("JSON OK")'
```

이 검사는 구문만 확인합니다. `node anilife.js`처럼 실행하면 앱이 제공하는 `MProvider` 등이 없어 동작하지 않습니다. 기능 확인은 Mangayomi에서 수행하거나, 호스트 객체와 사이트 응답을 제공하는 별도 테스트 환경이 필요합니다.

수정 후 앱에서는 다음을 확인하세요.

1. 인기·최신 목록과 다음 페이지가 중복·누락 없이 표시되는지 확인합니다.
2. 검색어 입력과 빈 검색어 필터를 각각 확인합니다. 애니24는 필터 구역 하나를 선택합니다.
3. 작품 상세와 여러 페이지에 걸친 회차 목록을 확인합니다.
4. 제목 언어·서버·오디오·자막 설정을 변경하고 화면을 새로고침합니다.
5. 회차 재생, 탐색, 오디오·자막 전환과 필요한 경우 다운로드를 확인합니다.

### 배포 파일 갱신

확장을 수정할 때는 해당 JS의 `mangayomiSources`와 등록 JSON의 버전·설명을 함께 갱신합니다. 기본 주소, `apiUrl`, `appMinVerReq`, `sourceCodeUrl`도 대조하세요. 기존 설치의 업데이트 연결을 유지하도록 배포 중인 확장 ID는 유지합니다.

수정한 JS와 JSON을 각 `sourceCodeUrl`이 가리키는 저장소·브랜치에 업로드한 뒤 앱에서 저장소 목록을 새로고침합니다.

## 알려진 문제 및 검증 범위

2026-10-15 로컬 파일 분석 기준입니다.

- **애니라이프:** 등록 JSON에 `현재 고장남`이 명시되어 있습니다. JS에는 API·세션 재시도 코드가 있으나 실제 동작 복구는 확인하지 않았습니다.

- ReAnime는 `source.apiUrl`이 있으면 이를 우선 사용합니다. 사이트 주소 설정만 바꾸어도 API 호스트가 함께 변경되는지는 적용된 메타데이터를 확인해야 합니다.
- 애니24의 JS 내부 메타데이터에는 `id`와 `appMinVerReq`가 없고, 등록 JSON에 각각 `780920260910802`, `0.9.2`가 선언되어 있습니다.
- 애니24 상단 주석은 MHT 스냅샷을 바탕으로 수정했으며 브라우저·실제 재생 검증을 수행하지 않았고, 고급 목록 쿼리 키가 잠정적이라고 밝히고 있습니다. 해당 스냅샷은 이 폴더에 포함되어 있지 않습니다.
- 이번 문서 작성 시 JS 5개의 `node --check`와 등록 JSON 파싱을 통과했습니다. 실제 사이트 요청, 앱 설치·재생, 다운로드는 검증하지 않았습니다.

## 연결·재생 문제 확인

- 목록이 비거나 형식 오류가 나면 사이트 주소, 확장 버전, 원본 페이지 구조 변경 여부를 확인하세요.
- 401·403 또는 영상 서버 오류가 나면 원본 사이트의 해당 회차가 브라우저에서 재생되는지 확인하세요. 코티비씨·애니라이프는 세션 처리, ReAnime는 플레이어·CDN 응답에도 영향을 받습니다.
- 제목 언어가 반영되지 않으면 목록·상세를 새로고침하세요. 원제 정보가 없으면 기존 제목이 유지될 수 있습니다.
- 업데이트가 보이지 않으면 저장소 목록을 새로고침하고 JSON의 `version`, `sourceCodeUrl`, 실제 배포 파일을 확인하세요.
