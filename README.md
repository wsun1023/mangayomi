# Mangayomi 미디어 확장

Mangayomi 형식의 JavaScript 미디어 확장을 관리하는 저장소입니다. 애니메이션과 영화·드라마 사이트의 작품 목록, 검색, 회차 정보, 재생 주소를 제공합니다.

## 확장 목록

이 저장소에서 직접 관리하는 JS 파일입니다.

| 이름 | 파일 | 버전 | 주요 기능 |
| --- | --- | --- | --- |
| 애니라이프 | [anilife.js](anilife.js) | 0.2.1 | 인기·최신·검색·필터, 작품·회차 정보, 제목 언어 설정 |
| 링크애니 | [linkani.js](linkani.js) | 0.2.0 | 인기·최신·검색, 분류·요일·연도 필터, 상세 원제, 회차·서버 구분 |
| 코티비씨 | [kotbc.js](kotbc.js) | 0.1.1 | 영화·드라마·예능시사·해외드라마, 검색·필터, 회차 전체 페이지, HLS 재생 |
| 애니24 | [ani24.js](ani24.js) | 0.1.19 | 작품·회차 조회, 검색, 영상 주소 해석 |
| ReAnime | [reanime.js](reanime.js) | 0.1.6 | 한국어 제목 검색, 스트리밍 주소 해석 |

확장 등록 정보는 [mangayomi-extensions-updated.json](mangayomi-extensions-updated.json)에 있습니다. 이 목록에는 외부에서 관리하는 IPTV, 삼성 TV 플러스, 티비룸, 라이브 TV·라디오도 포함되어 있습니다.

## 설치 및 업데이트

사용 중인 앱의 확장 저장소 또는 소스 설정에 다음 확장 목록 URL을 등록하세요.

```text
https://raw.githubusercontent.com/wsun1023/mangayomi/main/mangayomi-extensions-updated.json
```

1. 저장소 목록을 새로고침합니다.
2. 사용할 확장을 설치하거나 업데이트합니다.
3. 확장 설정에서 사이트 주소, 제목 언어, 자막 등의 옵션을 조정합니다.
4. 작품 목록과 회차 재생을 확인합니다.

애니라이프·링크애니·코티비씨의 최소 Mangayomi 버전 표기는 `0.9.2`입니다. MOA에서도 실제 목록·재생 동작을 확인해야 합니다.

## 최근 변경

### 코티비씨 0.1.1

- 익명 HTTP 세션과 CSRF 쿠키를 사용해 사이트의 ‘바로 보기’와 동일하게 새 재생 주소를 발급받습니다.
- 발급된 플레이어 주소를 Referer로 전달하고, FirePlayer 영상 API에서 HLS 재생 주소를 가져옵니다.
- 기존 영상 주소에 바로 접속했을 때 발생하던 404 문제를 수정했습니다.
- 인기 탭은 사이트의 **평점 높은순**, 최신 탭은 **업데이트 최신순**을 사용합니다.
- 상세에서는 페이지를 끝까지 조회해 회차 목록을 합칩니다.

### 링크애니 0.2.0

- 현재 사이트 구조를 기준으로 목록·검색·상세·재생 처리를 다시 작성했습니다.
- `dc-toki-mangayomi-media.pages.dev`, Jina 중계, 외부 도메인 조회 의존성을 제거했습니다.
- 중첩된 작품 카드와 페이지 이동 링크를 처리하고, 회차와 서버를 구분합니다.
- 상세 원제는 사이트가 제공하는 정보를 사용합니다. 목록은 사이트에 표기된 제목을 표시합니다.

### 애니라이프 0.2.1

- 목록·상세·재생 API를 애니라이프 사이트에 직접 연결합니다.
- `dc-toki-mangayomi-media.pages.dev` 중계와 아이콘 의존성을 제거했습니다.
- 인기·최신·검색·필터, 한국어·일본어 제목, 회차 정보와 자막 설정을 지원합니다.

## 개발 및 테스트

Node.js에서 자동 테스트를 실행할 수 있습니다.

```sh
node --test tests/anilife.test.cjs tests/linkani.test.cjs tests/kotbc.test.cjs
```

실제 사이트 요청을 확인하는 테스트는 네트워크 연결이 필요합니다.

```sh
node tests/kotbc.live-smoke.cjs
node tests/anilife.live-smoke.cjs
```

확장을 수정할 때는 해당 JS 파일과 확장 목록 JSON의 버전·설명을 함께 갱신하고, 두 파일을 GitHub에 업로드하세요. 기존 설치를 업데이트할 수 있도록 확장 ID는 유지하세요.

## 연결 문제 확인

- 사이트 주소가 변경되면 확장 설정의 **사이트 주소**를 갱신하세요.
- 업데이트가 반영되지 않으면 저장소 목록과 설치된 확장 버전을 확인하세요.
- 재생 오류를 보고할 때는 확장 이름·버전, 작품·회차 주소, 오류 메시지, 사이트 브라우저 재생 여부를 함께 알려주세요.
